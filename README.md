# Fracciones sin Miedo 🍕

Presentación educativa interactiva de 12 diapositivas para aprender fracciones, decimales y resolución de problemas paso a paso de forma visual y sencilla.

## Contenido incluido
1. ¿Qué es una fracción? (con barra de chocolate interactiva y pizza ajustable)
2. Tipos de fracciones: homogéneas, heterogéneas, propias e impropias
3. Fracciones equivalentes (amplificación y simplificación visual)
4. Fracciones mixtas e impropias
5. Relación de orden y truco de la cruz
6. Suma y resta de fracciones (homogéneas y método de la "carita feliz")
7. Multiplicación y división de fracciones
8. Fracción de un número
9. Conversión entre fracciones y números decimales
10. Estrategias paso a paso para resolver problemas + mini reto interactivo

## Archivos
- `index.html`: Presentación web interactiva (HTML + Tailwind CSS + JavaScript Vanilla).
- `guia_facil_fracciones.md`: Guía completa escrita con ejemplos cotidianos.
